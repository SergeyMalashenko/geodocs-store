# Поиск и скачивание с docs.cntd.ru

## Что отдаёт портал

- Карточка документа: `https://docs.cntd.ru/document/<id>`.
- Полный текст — блоками через публичный API:
  список блоков `docs.cntd.ru/api/document/<id>/content/text/blocks/size`,
  каждый блок `.../content/text/block/<n>?query=&strict=strict`.
- Мета-информация: `https://api.docs.cntd.ru/document/<id>`.

## Как искать

1. `search_document` с `portal="cntd"` ищет по номеру и названию и
   возвращает `document_id` в meta кандидата.
2. Точный `document_id` можно взять и из веб-поиска по запросу вида
   `site:docs.cntd.ru <номер документа>`.
3. Проверяй соответствие редакции: дата редакции в мета-информации должна
   совпадать с искомой `version_date`.

## Платное и бесплатное

Бесплатно — публичный полный текст (HTML-фрагменты, склеиваются в один
`.html`; экстракторы geodocs читают такие таблицы ВРИ). Платные приложения,
сканы оригиналов и ГОСТы с ограниченным доступом через API не добываются —
если блоки пустые, это не баг, ставь `"status": "not_found"` и ищи дальше.

## Скачивание

`download_document(url=<карточка>, portal="cntd")` сам склеит блоки в
`cntd_<id>.html` в inbox. Имя файла фиксированное — не переименовывай,
гейт сверяет содержимое, а не имя.
