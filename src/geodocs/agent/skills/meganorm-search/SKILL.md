# Поиск и скачивание с meganorm.ru

## Что это

Нормативная база строительных документов (СНиП, ГОСТ, СП, методические
указания). Это НЕ источник муниципальных ПЗЗ и генпланов: если поиск
«ПЗЗ Шатуры» выдал meganorm — почти наверняка ложное срабатывание по
слову в тексте какого-то СП.

## URL-схема

- Карточки и полные тексты: `https://meganorm.ru/Data2/<раздел>/<id>/<docid>.htm`
  — это HTML полного текста документа, а не файл.
- Поиск по базе: `https://meganorm.ru/Search2/search?q=<текст>`.

## Главная ловушка

Прошлые прогоны агент сохранял `.htm`-страницы как «документ». Гейт приёма
HTML отклоняет, и правильно. Правила:

1. Ссылка вида `/Data2/.../*.htm` — всегда HTML-текст. Не сохраняй её как файл.
2. Инструмент `import_document` с `portal="meganorm"` сам откажется
   сохранять HTML и импортирует файл, только если на карточке есть прямая
   ссылка на `.pdf`/`.doc`/`.zip`.
3. Если файла нет — документ доступен только в HTML: это допустимый
   результат только для справочных СП/ГОСТ, но НЕ для ПЗЗ/генпланов:
   ставь в MANIFEST `"status": "not_found"` и ищи на другом портале.

## Когда meganorm реально полезен

Когда цель — текст строительного норматива (СП 42.13330 и т.п.), а не
муниципальный документ. Тогда HTML-страницу можно прочитать как
оглавление через `import_document`.
